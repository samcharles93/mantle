## Findings

- Go 1.27 changed the experimental `simd/archsimd` API and introduced portable `simd`; `GOEXPERIMENT=simd` is still needed. Installed compiler was Go 1.27.0. Go 1.27.1 is available and includes SIMD fixes. Sources: [Go 1.27 release notes](https://go.dev/doc/go1.27), [Go SIMD blog](https://go.dev/blog/simd-experiment), [release history](https://go.dev/doc/devel/release).
- MiniCPM5 base checkpoint declares `LlamaForCausalLM`, 42 layers, hidden 2048, 16 query/2 KV heads, head dim 128, context 131072, and standard Llama weight names. The base architecture is structurally mappable, but no full model run or quality comparison was performed. Source: [official MiniCPM5 2B](https://huggingface.co/openbmb/MiniCPM5-2B).
- Official DSpark checkpoint declares `Qwen3DSparkModel`, 5 draft layers, block size 7, target hidden state taps `[1,10,20,30,39]`, a projector, Markov head, and confidence head. Mantle has no DSpark runtime, target hidden state capture, multi-token verification, or KV rollback. The current sequential `ForwardTokens` is correct but does not provide fast batch verification. Source: [official DSpark model](https://huggingface.co/openbmb/MiniCPM5-2B-DSpark) and [llama.cpp speculative decoding docs](https://github.com/ggml-org/llama.cpp/blob/master/docs/speculative.md).
- No MiniCPM5 safetensors or MCF checkpoint is local. The GGUF pair exists on `carina` but Mantle's MCF path should be exercised using the official safetensors, not GGUF conversion. No full model download is in progress.
- CUDA 13.2 `nvcc` rejects the system default GCC 16; kernels compile with `NVCC_PREPEND_FLAGS='-ccbin=/usr/bin/gcc-15' bash scripts/build_cuda.sh`. Tagged Go build needs `CGO_LDFLAGS='-L/usr/local/cuda-13.2/targets/x86_64-linux/lib'` and matching `LD_LIBRARY_PATH`.
